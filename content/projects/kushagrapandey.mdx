<span id="architecture-and-decisions" />

## Architecture

**Next.js App Router** serves the pages. **Contentlayer** compiles MDX into project data at build time, and **Tailwind CSS** provides the styling. **Framer Motion** connects the introductory typography, scroll-driven project panels, navigation feedback, and page transitions.

**Upstash Redis** records project page views through an API that deduplicates by a hashed IP/project key. **Vercel** hosts the site. The game loads when requested, keeping it out of the initial experience.

Static content and interaction code stay separate so the portfolio remains readable while enhancements load. Reduced-motion styles retain the content and navigation with less movement.
